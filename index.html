English

Subtitle Companion creates subtitles from playback audio that other Android apps permit to be captured. No app account is required.

Audio and translation

Playback audio is recognized exclusively on the device by SenseVoice for supported languages. The app does not open the microphone, save audio files, or send playback audio off the device. Only audio shared under Android playback-capture rules is available; protected content may be unavailable.

Once offline Google ML Kit translation packs finish downloading quietly in the background (Wi-Fi by default, or mobile data if allowed in Settings), text translation runs 100% on the device. While local translation packs are still downloading, finalized subtitle sentences (text only, never audio) are sent ephemerally over TLS HTTPS to our relay (us.adsshare.org) backed by Tencent HY-MT2-1.8B to provide instant captions within a 60 active minutes per day per device quota. Neither our relay server nor its logs retain or log subtitle text; a random per-install UUID is SHA-256 hashed on the server solely to count the daily quota.

Stored information and deletion

Subtitle history is enabled by default and stores recognized text, translations and session times only in the app’s private local database. You can disable future history, delete individual sessions or clear all history in the app. Disabling history does not delete existing sessions. No audio recordings are stored. Language, download, random install quota identifier, and caption appearance preferences are stored locally. App data is excluded from Android cloud backup and device transfer. Clearing app storage or uninstalling deletes all local app data.

Model downloads and external services

Speech models may be bundled in the installation or downloaded from Hugging Face and GitHub; offline translation packs are downloaded through Google ML Kit. These providers receive network requests, which can include an IP address and routine device or service information, and may keep logs under their own policies. Temporary cloud fallback sends only finalized subtitle sentences, language tags, and the random install identifier to us.adsshare.org and Tencent Cloud TokenHub for immediate translation, with zero subtitle retention on our relay. The app contains no advertising integration. Anonymous setup funnel, latency, and error diagnostics are collected by default via GameAnalytics (com.gameanalytics.sdk:gameanalytics-android:7.2.1, with an opt-out toggle in Settings). Opening this public policy page uses GitHub Pages and is subject to GitHub’s website privacy practices. Sending support email shares the information you choose to include with the developer and email providers; avoid including audio or private subtitles unless needed.

Third-party SDK diagnostics

Google ML Kit also uses SDK diagnostics and usage analytics. Google may receive device and app information, installation identifiers, performance and error metrics, feature events, and configured source and target languages. Translation uses Firebase installations and remote configuration services for diagnostics. In addition, the GameAnalytics Android SDK (com.gameanalytics.sdk:gameanalytics-android:7.2.1) collects anonymous setup funnel, latency, and error diagnostics using Google Play App Set ID (play-services-appset) with Google Advertising ID tracking explicitly disabled (setGAIDTracking(false)). Neither audio nor subtitle text is ever sent to GameAnalytics, and you can opt out anytime in Settings. This is separate from local subtitle processing and from model-file download requests. Google and GameAnalytics handle SDK transport under their own privacy policies; do not interpret offline translation as an absence of all SDK network activity.

Local history remains on the device until you delete it, clear app storage or uninstall. Support emails are kept only as needed to handle your request. Contact the support email for requests about information you sent directly to the developer. The app has no user account, and local history can be deleted without contacting support.

Android permissions

RECORD_AUDIO is required by Android for playback capture; this app’s capture configuration does not use microphone input. MediaProjection requires Android’s confirmation when starting a session. The foreground service and notifications show the running session and provide pause/stop actions. Picture-in-picture places subtitles over another app using Android’s PiP controls; the app does not request the SYSTEM_ALERT_WINDOW overlay permission. Internet and network-state access support model downloads and temporary hybrid cloud fallback translation.

Your choices and contact

You can stop capture at any time, use downloaded offline packs for 100% local translation, use original-only captions, disable optional history, disable anonymous GameAnalytics diagnostics in Settings, clear app storage, and delete local history. For privacy questions or requests concerning information you send directly to the developer, contact feixuwu@gmail.com. The app has no registration flow and does not ask for a birth date; the developer does not intentionally solicit children’s personal information.

中文

字幕伴侣根据其他 Android 应用允许共享的播放音频生成识别和翻译字幕，无需注册应用账户。

音频与翻译

播放音频的语音识别完全在设备本机由 SenseVoice 完成；本应用不打开麦克风、不保存音频文件，也绝不会将播放音频发送出设备。只能捕获符合 Android 播放音频共享规则的内容，受保护内容可能无法捕获。

所需 Google ML Kit 离线翻译包会在符合条件时于后台静默下载（默认仅限 Wi-Fi，可在设置中允许移动网络下载），就绪后所有翻译完全在本地完成。在本地翻译包下载完成前，仅会将已识别完结的字幕句子文本（纯文本，不包含音频）通过 HTTPS TLS 加密发送至中继服务（us.adsshare.org）调用腾讯 HY-MT2-1.8B 进行即时翻译（每日每设备限 60 分钟免费额度）。我们的中继服务器与日志均不存储或保留字幕内容，服务端仅对随机安装 UUID 做 SHA-256 哈希以统计每日额度；本地翻译包下载完成后会自动切换回纯本地离线翻译。

本地保存与删除

字幕历史默认启用，只在应用私有的本地数据库保存识别原文、译文和会话时间。用户可以关闭后续保存、删除单个会话或清除全部历史；关闭保存不会删除已保存的历史。应用不保存音频录音。语言设置、下载选项、随机额度安装标识及字幕外观偏好仅保存在本地。应用数据不参与 Android 云备份和设备迁移。清除应用数据或卸载会删除应用本地数据并重置随机标识。

模型下载与外部服务

语音模型可能随安装包提供，或从 Hugging Face、GitHub 下载；离线翻译包通过 Google ML Kit 下载。这些提供方会收到网络请求，可能包含 IP 地址及常规设备或服务信息，并按各自政策保留日志。临时云端辅助翻译仅向 us.adsshare.org 及腾讯云 TokenHub API 发送字幕文本、语种标识和随机安装 ID 以获取译文，中继服务器不留存任何字幕文本。应用不集成广告服务；默认（可在设置中关闭）通过 GameAnalytics（com.gameanalytics.sdk:gameanalytics-android:7.2.1）收集匿名引导流程、耗时和错误诊断数据。

第三方 SDK 诊断

Google ML Kit 还使用 SDK 诊断及使用情况分析。Google 可能收到设备和应用信息、安装标识、性能和错误指标、功能事件，以及配置的原文和目标语言。翻译 SDK 使用 Firebase 安装及远程配置服务进行诊断。此外，应用使用 GameAnalytics Android SDK（com.gameanalytics.sdk:gameanalytics-android:7.2.1）收集匿名引导漏斗、耗时及错误诊断数据，使用 play-services-appset App Set ID，已显式关闭广告 ID 跟踪（setGAIDTracking(false)），绝不上传音频或字幕文本，用户可随时在“设置”中关闭。

本地历史保留在设备上，直到用户删除、清除应用数据或卸载。应用不创建用户账户，删除本地历史不需要联系开发者。

Android 权限

Android 要求录音权限（RECORD_AUDIO）以控制播放音频捕获；本应用的捕获配置不使用麦克风输入。每次启动会话时，媒体投射（MediaProjection）由 Android 请求用户确认。前台服务和通知展示运行状态，并提供暂停、结束操作。画中画通过 Android PiP 控件在其他应用上方显示字幕，应用不请求 SYSTEM_ALERT_WINDOW 悬浮窗权限。网络和网络状态权限用于模型下载及本地包尚未下载完时的临时云端辅助翻译。

用户选择与联系

用户可以随时停止捕获、使用离线翻译包进行纯本地翻译、关闭历史保存、在设置中关闭匿名诊断统计、清除应用数据以及删除本地历史。有关隐私问题请联系 feixuwu@gmail.com。
